# Data sources and their licenses

The MIT license in [`LICENSE`](LICENSE) covers the CODE in this repository only.
No dataset is redistributed here. Every input is obtained from its own source,
under its own terms:

- Prov-GigaPath TCGA slide embeddings (CC-BY-4.0)
- MSigDB Hallmark gene sets, v2024.1 (CC-BY-4.0)
- Xena TOIL expression
- PanCanAtlas ABSOLUTE purity
- TCGA Clinical Data Resource (TCGA-CDR)
- the published UCSF ancestry calls

BostonGene/MFP signature definitions are deliberately NOT used: their license
restricts use to academic and non-profit purposes and defines "Source Form" to
include data.

*(Until 2026-09-24 this note was appended to `LICENSE` itself, which made
GitHub's license detection read the repository as `NOASSERTION` rather than
MIT. It was split out, unchanged in substance, so that `LICENSE` is the
verbatim MIT text.)*
